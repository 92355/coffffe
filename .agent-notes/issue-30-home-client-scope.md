## What to build

홈 화면의 클라이언트 렌더링 범위를 줄인다. 정적인 홈 콘텐츠는 서버 컴포넌트로 유지하고, 사용자 상태, 로그인 버튼, 프로필 편집처럼 브라우저 상태가 필요한 영역만 클라이언트 컴포넌트로 분리한다.

## Acceptance criteria

- [ ] 홈 화면 전체가 불필요하게 클라이언트 컴포넌트로 묶이지 않는다.
- [ ] 로그인 버튼, 로그아웃, 프로필 버튼, 관리자 링크 표시 조건이 기존처럼 동작한다.
- [ ] 원두 카드, 지도 링크, CBTI/원두 정보 링크가 기존처럼 동작한다.
- [ ] 프로필 편집 시트는 기존 기능을 유지한다.
- [ ] `npx tsc --noEmit`, `npm run lint`, `npm run build`를 실행하고 결과를 남긴다.

## Blocked by

None - can start immediately
