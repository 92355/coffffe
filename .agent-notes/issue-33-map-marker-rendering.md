## What to build

지도 화면의 마커 렌더링 비용을 줄인다. 필터, 검색, 선택 상태 변경 시 모든 overlay를 삭제하고 다시 만드는 구조를 개선하고, 모바일에서는 모든 마커의 증기 애니메이션이 계속 실행되지 않도록 제한한다.

## Acceptance criteria

- [ ] 필터/검색 변경 후 표시되는 마커 목록이 기존과 동일하게 유지된다.
- [ ] 카페 마커 선택, 선택 해제, 지도 중심 이동 동작이 기존처럼 유지된다.
- [ ] 마커 overlay 전체 재생성이 필요한 경우와 재사용 가능한 경우가 분리된다.
- [ ] 모바일에서는 선택된 마커 또는 제한된 조건에서만 증기 애니메이션이 실행된다.
- [ ] 지도 화면 모바일 viewport에서 마커 선택과 필터 변경을 수동 QA하고 결과를 남긴다.
- [ ] `npx tsc --noEmit`, `npm run lint`, `npm run build`를 실행하고 결과를 남긴다.
