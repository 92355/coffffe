## What to build

카카오 로그인 성공 후 사용자 상태가 늦게 반영되는 흐름을 줄인다. callback에서 이미 확보한 사용자 정보를 활용하고, 로그인 직후 클라이언트와 서버가 같은 사용자 정보를 중복 조회하는 구조를 최소화한다.

## Acceptance criteria

- [ ] 로그인 성공 후 원래 페이지로 돌아오는 동작이 유지된다.
- [ ] 로그인 성공 후 사용자 프로필 반영이 기존보다 빠르게 일어난다.
- [ ] 기존 유저 로그인 시 불필요한 Supabase 왕복이 줄어든다.
- [ ] 인증 쿠키가 없을 때는 기존처럼 익명 사용자 상태로 처리된다.
- [ ] 로그인 실패 시 기존 실패 처리 흐름이 유지된다.
- [ ] 관련 인증 API 또는 사용자 상태 훅 테스트를 추가하거나, 테스트가 어려운 경우 수동 검증 절차를 명시한다.
- [ ] `npx tsc --noEmit`, `npm run lint`, `npm run build`를 실행하고 결과를 남긴다.

## Blocked by

None - can start immediately
