## What to build

홈, 지도, 로그인 성능 개선 작업이 끝난 뒤 모바일 성능 회귀 검증 기준을 정리하고 실행한다. 자동 검증과 모바일 viewport 수동 QA 결과를 남겨 이후 작업에서 같은 문제가 재발하지 않게 한다.

## Acceptance criteria

- [ ] 홈 모바일 진입, 홈 스크롤, 지도 진입, 지도 조작, 로그인 복귀를 포함한 수동 QA 체크리스트가 정리된다.
- [ ] 개선된 홈과 지도 화면을 모바일 viewport에서 확인하고 결과를 기록한다.
- [ ] 로그인 성공/실패/로그아웃 흐름을 확인하고 결과를 기록한다.
- [ ] `npx tsc --noEmit`, `npm run lint`, `npm run build` 최종 결과를 기록한다.
- [ ] 남은 성능 리스크가 있으면 후속 작업으로 분리할 수 있게 기록한다.
